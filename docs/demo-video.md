# Demo video script (M-34)

**Length:** 60–90 s · captions only · no voiceover  
**Host:** YouTube unlisted or GitHub release asset · embed GIF in README

## Shot list

| # | Shot | Caption |
|---|---|---|
| 1 | Login → biometric unlock | Sign in |
| 2 | Warehouse select | Pick warehouse |
| 3 | Inventory search | Find a SKU |
| 4 | Scan (or manual SKU) → balance detail | Scan |
| 5 | **Airplane mode ON** | Offline |
| 6 | Adjust stock → success + pending badge | Instant — queued |
| 7 | Sync centre shows PENDING | Sync centre |
| 8 | **Airplane mode OFF** | Back online |
| 9 | Watch status → Synced | Synced |
| 10 | Conflict modal (prep a second adjust on server) | Resolve conflict |
| 11 | Toggle dark mode | Dark mode |

## The money shot

Steps 5–9 are the architecture in fifteen seconds. Rehearse until the pending badge and sync are unmistakable without narration.
